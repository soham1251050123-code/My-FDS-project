System Architecture & Data Structures
1. State Representation (3D Array)

The cube state is stored in memory as cubeArray[6][3][3]. The 6 faces map to indices 0 (Up), 1 (Right), 2 (Front), 3 (Down), 4 (Left), and 5 (Back). Each face maintains a 3×3 matrix of sticker color codes, serving as the single authoritative source of truth.

2. History Stack (LIFO)

Tracks executed move vectors with an explicit TOP pointer. Each completed rotation pushes a move token to the stack. Invoking Undo pops the top element and executes its mathematical inverse, restoring the prior permutation.

3. Execution Queue (FIFO)

Buffers planned solving sequences with distinct FRONT and REAR pointers. In Auto Solve and Step-by-Step modes, moves are dispatched strictly first-in, first-out to ensure deterministic execution.

4. Solver Pipeline

Utilizes Herbert Kociemba's two-phase algorithm. Phase 1 coordinates group reduction from general permutation group G into subgroup H. Phase 2 computes optimal permutation paths to identity I in ≤ 20 moves.
